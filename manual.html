家計簿アプリ 使い方マニュアル

この家計簿アプリは2つの使い方があります。

PC版iPhone単独版(PWA)
場所http://127.0.0.1:8765（PC内）<br>http://192.168.3.7:8765（同一Wi-Fiのスマホ）https://k333hama.github.io/kakeibo/
PCの起動が必要必要（サーバー起動中のみ）不要（オフラインでも動く）
データの保存先PC内のDBファイル D:\kakeibo_app\kakeibo.dbiPhone本体
使い方下の「共通の使い方」下の「iPhone単独版」+「共通の使い方」

1. PC版の起動

  • タスクバーの検索で「cmd」と入力 → コマンドプロンプトを開く
  • 次を入力してEnter:

    • `

    cd /d D:\kakeibo_app

    python server.py

    `

  • ブラウザで http://127.0.0.1:8765 を開く
  • 終了したいときはサーバーの窓で Ctrl+C（または窓を閉じる）

    • ※ 起動ログに iPhone等から同じWi-Fiでアクセス: http://192.168.3.7:8765 と出ます。このIPはルーター環境で変わることがあるので、接続できないときはログのURLを確認してください。

    ※ 最初に一度だけ、ファイアウォールの許可が必要です：

    D:\kakeibo_app\iPhoneアクセス設定(管理者で実行).bat を 右クリック → 管理者として実行

    2. iPhone単独版(PWA)の入れ方

  • iPhoneの Safari で https://k333hama.github.io/kakeibo/ を開く
  • 共有ボタン（□に↑のマーク）をタップ
  • 「ホーム画面に追加」 をタップ
  • ホーム画面のアイコンから起動
  • ホーム画面から起動すると全画面のアプリとして動きます
  • 電波がない場所でも使えます（データはiPhoneの中に保存）
  • 初期データ（今までの明細）が入った状態です

    • 3. 共通の使い方

    支出を登録する

  • 画面の 日付・金額・カテゴリー・店・メモ を入力

    • - カテゴリー・店は入力欄に文字を入れると、よく使う順（件数の多い順）に候補が出ます

  • メモの右横の 「登録」 ボタンをタップ/クリック
  • 下の「今月の明細」にすぐ追加されます

    • 月を切り替える

  • 上段の ◀ ▶ ボタン で前月・翌月
  • 中央の 年月のプルダウン で任意の年月へジャンプ

    • 4つのカード

    カード意味
    支出合計表示中の月の支出の合計
    予算残高設定の予算 − 今月の支出
    前月比前月と比べて増えた/減った金額
    残高収入 − 支出の累計

    グラフ

  • 円グラフ: 表示中の月の費目別内訳
  • 棒グラフ: 月別支出推移。「過去6ヶ月」「過去1年」を切り替え可能

    • 明細の修正・削除

  • 明細の行をクリック/タップすると編集窓が開きます
  • 金額・日付・カテゴリー・店・メモを直して 「保存」
  • 消したいときは 「削除」（確認が出ます）

    • 設定（⚙ボタン）

  • 予算の入力（例: 30000）→ 保存
  • カテゴリー・店名の管理

    • - チップ（ボタン状の一覧）は使った件数の多い順に並び、件数バッジが付きます

    - チップを押すと、そのカテゴリー/店の全月の明細一覧が出ます（行を押すと修正・削除）

    - ✎ … 名前の変更（過去の明細もまとめて書き換わります）

    - ✕ … 候補リストから削除（明細自体は残ります）

    - 下の入力欄で新しいカテゴリー・店名を追加できます

    4. PCとiPhoneのデータの同期

    iPhoneで登録した支出をPCへ、またはその逆に移す方法です。

  • 移す側のアプリで ⚙設定 → JSONを書き出す を押す（kakeibo-backup-….json がダウンロードされます）
  • 受け取る側のアプリで ⚙設定 → JSONを読み込み からそのファイルを選ぶ
  • 読み込み側は明細がファイルの内容に置き換わります（マージではない）

    • ※ 置き換え前に、現在のデータを念のため書き出しておくと安全です。

    5. 注意点

  • iPhone単独版のURLは一般公開されています（URLを知る人は初期データを見られます）。削除・非公開にしたければ言ってください
  • iPhone単独版のデータはiPhoneの中にだけあります。iPhoneを買い替える前に JSONを書き出してバックアップ してください
  • PC版のデータは D:\kakeibo_app\kakeibo.db です。フォルダごとバックアップすると安心です
  • Excel（D:\家計簿\家計簿.xlsm）からの再取り込みはアプリのボタンからは無効です（必要なら依頼してください）
